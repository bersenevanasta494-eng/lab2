# lab2
# Карточка 1: Домашняя бухгалтерия


## Цель проекта

Создать MVP десктопного или консольного/веб-приложения для совместного и
личного учета доходов, расходов и контроля семейного бюджета без лишней суеты.

## Модуль 1. Управление транзакциями (TransactionsModule)

- **Класс:** Transaction / TransactionService
- **Функционал:** Добавление операции (сумма, категория, дата, тип: расход/доход,
  комментарий). Удаление и редактирование записей.

## Модуль 2. Категории и Бюджеты (Budget Module)

- **Класс:** Category / BudgetManager
- **Функционал:** Список категорий (еда, подписки, транспорт и т.д.). Установка
  лимита трат на категорию на месяц и проверка: «Превышен ли лимит по
  категории?».

## Модуль 3. Аналитика и Отчеты (Analytics Module)

- **Класс:** AnalyticsService / FinancialReport
- **Функционал:** Подсчет общего баланса, расчет суммы расходов за выбранный
  период, вычисление топ-3 самых затратных категорий.

## Модуль 4. Хранение данных и Экспорт (Data Storage Module)

- **Класс:** DataRepository / FileStorage
- **Функционал:** Сохранение истории операций и настроек бюджета в файл
  (JSON / CSV / SQLite) и чтение данных при запуске приложения.

---

## Соответствие требованиям

| Требование задания | Реализация | Где проверить |
|---|---|---|
| Добавление операции | `TransactionService.add` | Меню «1) Добавить операцию» |
| Редактирование записей | `TransactionService.edit` | Меню «3) Редактировать операцию» |
| Удаление записей | `TransactionService.delete` | Меню «4) Удалить операцию» |
| Список категорий | `DataRepository.categories` | Меню «5) Категории» |
| Установка лимита на месяц | `BudgetManager.set_limit` | Меню «7) Бюджетные лимиты» |
| Проверка «превышен ли лимит» | `BudgetStatus.is_exceeded`, `BudgetManager.check` | Меню «8) Проверка лимитов за месяц» |
| Общий баланс | `AnalyticsService.balance` | Меню «9) → 1) Общий баланс» |
| Расходы за период | `AnalyticsService.expenses` | Меню «9) → 2) Отчёт за период» |
| Топ-3 затратных категорий | `AnalyticsService.top_categories` | Меню «9) → 3) Топ-3 категорий» |
| Сохранение в файл | `FileStorage.write` (CSV) | Каталог `data/` |
| Чтение при запуске | `DataRepository.load` | Каждая сессия приложения |

Формат хранения выбран **CSV** из трёх предложенных в задании.
Тип приложения — **консольное**, а не десктопное или веб.
